GOLDMAX door-production — GÓI DELTA V100 (danh sách đơn hàng chia 2 cột — Phương án B)
======================================================================================

Gói này CHỈ chứa các file thay đổi so với bản door-production.zip gốc (24/09/2026).
Cách áp dụng: copy đè toàn bộ nội dung gói này vào thư mục gốc dự án (giữ nguyên cây thư mục).

NỘI DUNG
--------
Màn Quản lý đơn hàng (/orders) chuyển sang bố cục 2 cột:
- Cột trái: tab trạng thái (Tất cả / Đơn hàng mẫu / Sản xuất) + 3 chỉ số (tổng đơn,
  tổng tiền, quá hạn) + danh sách đơn gọn + PHÂN TRANG 20 đơn/trang.
- Cột phải: chi tiết đơn đang chọn (thông tin nhận hàng, 4 ô tổng, bảng hàng hóa 13 cột,
  nút Sửa / Xuất Excel / Xuất PDF / Xóa, link In và xem đầy đủ 23 cột). Không cần mở trang mới.
- Thanh lọc: thêm TÌM NHANH + chip khoảng ngày (Hôm nay/Tuần/Tháng/Quý/Năm) + LỌC TRẠNG THÁI.
- Nút "Xuất Excel danh sách" giờ lọc đúng như trên màn (dùng chung bộ lọc).

SỬA KÈM: ngày đơn/hạn giao trước đây hiển thị lệch 1 ngày (format theo giờ máy chủ) — nay format theo UTC.

DANH SÁCH FILE
--------------
Mới:
  src/components/order-list/order-list-pane.tsx     cột trái
  src/components/order-list/order-detail-pane.tsx   cột phải
  src/components/order-list/format.ts               định dạng ngày/tiền dùng chung
  src/lib/order-list-filters.ts                     bộ lọc dùng chung + dựng query
  ORDER_LIST_SPLIT_VIEW_V100.md                     tài liệu + bảng kiểm chứng
Sửa:
  src/app/orders/page.tsx                           bố cục 2 cột + truy vấn phân trang
  src/app/api/orders/export-list/route.ts           dùng chung bộ lọc (thêm q/status)

KHÔNG cần migration DB. Không đổi cấu trúc bảng dữ liệu.

BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build:
       rmdir /s /q .next
       del /s /q python\__pycache__ api\__pycache__
2. Chạy lại: npm run build (hoặc npm run dev).
3. Mở /orders: bấm 1 đơn ở cột trái → chi tiết hiện ngay cột phải; thử tìm nhanh,
   chip khoảng ngày, đổi tab trạng thái và phân trang.
