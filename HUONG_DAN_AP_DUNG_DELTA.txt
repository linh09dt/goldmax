GOLDMAX door-production — GÓI DELTA V106 (đồng bộ UI trang Theo dõi doanh thu)
=============================================================================

!!! ÁP DỤNG SAU GÓI V103. File này chứa cả nội dung V102 + V103 của trang doanh thu.

Cách áp dụng: copy đè nội dung gói này vào thư mục gốc dự án (giữ nguyên cây thư mục).

NỘI DUNG (chỉ đổi GIAO DIỆN, không đổi nghiệp vụ/dữ liệu)
---------------------------------------------------------
1. Hai bảng dùng hệ bảng chuẩn của app: class "erp-table erp-table-full" (đúng hệ bảng tab Cấu hình)
   → header nền đậm chữ IN HOA, chỉ kẻ ngang mảnh, hover xanh nhạt, ô số canh phải + tabular-nums
   (thay cho header màu tự chế #a9bee1 + kẻ ô cả dọc lẫn ngang như trước).
2. Thêm dòng "TỔNG CỘNG" cuối mỗi bảng (bảng đơn: tổng tiền, % CK bình quân + tiền CK, sau CK,
   đặt cọc, còn lại; bảng sản phẩm: tổng doanh thu).
3. Thanh lọc xếp theo lưới 12 cột giống tab Quản lý đơn hàng: nhãn IN HOA 10px, ô cao h-9,
   ghi rõ "Tất cả đại lý" / "Tất cả khách hàng", nút "⤓ Xuất Excel doanh thu" chuyển vào thanh lọc.
4. 5 ô tổng dùng kiểu ô tổng hợp của tab Quản lý đơn hàng (nhãn IN HOA 9,5px + số 15px đậm);
   ô "Còn lại" được làm nổi như ô "Còn phải thu".
5. Tiêu đề mỗi bảng gọn lại + hiện số lượng ở góc phải ("2 đơn", "3 sản phẩm").

DANH SÁCH FILE
--------------
Sửa:
  src/app/revenue/page.tsx        thanh lọc + 2 bảng + ô tổng + dòng tổng
  REVENUE_UI_SYNC_V106.md         tài liệu + kết quả kiểm chứng

KHÔNG cần migration DB. Các tham số lọc và số liệu giữ nguyên; file Excel xuất ra không đổi.

BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build:  rmdir /s /q .next
2. Chạy lại: npm run build (hoặc npm run dev).
3. Mở /revenue: bảng có header đậm chữ IN HOA, cột tiền thẳng cột, cuối bảng có dòng TỔNG CỘNG;
   thanh lọc giống tab Quản lý đơn hàng.

GHI CHÚ
-------
Nút "Xuất Excel doanh thu" nay nằm trong thanh lọc (giống tab Quản lý đơn hàng) thay vì ở tiêu đề bảng.
Muốn đưa về vị trí cũ thì nói.
