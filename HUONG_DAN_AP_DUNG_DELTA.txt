BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build:
       rmdir /s /q .next
       del /s /q python\__pycache__ api\__pycache__
2. Chạy lại: npm run build (hoặc npm run dev).
3. Mở Cấu hình → Cấu hình tính toán → bấm "Lưu cấu hình": các rule cùng Model nhưng
   khác cột "Bộ cửa chính" sẽ lưu được (trước đây báo "Cấu hình đang bị trùng: PR").
