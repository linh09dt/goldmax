GOLDMAX door-production — GÓI DELTA V94 (dọn tab Cấu hình tính toán)
====================================================================

Gói này CHỈ chứa các file thay đổi so với bản door-production.zip gốc (24/09/2026).
Cách áp dụng: copy đè toàn bộ nội dung gói này vào thư mục gốc dự án (giữ nguyên cây thư mục).

NỘI DUNG (3 việc trong tab Cấu hình tính toán)
---------------------------------------------
1. Tách "Thông số chung" thành 2 khu vực rõ ràng: LÀM TRÒN KH/LƯỢNG và BỘ SỐ.
2. Bỏ dải 5 ô ví dụ ở cuối trang (NHÓM CỬA / PHÀO-PHAO / Ô THOÁNG / KHÓA / BỘ SỐ).
3. Bảng rule: cột theo px + bề rộng tối thiểu 1660px nên KHÔNG còn cắt chữ
   ("Khuôn biệt thự...", "PR - Phào mặt t..."); màn hẹp thì cuộn ngang.

DANH SÁCH FILE
--------------

QUAN HỆ VỚI CÁC GÓI TRƯỚC

BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build:
       rmdir /s /q .next
       del /s /q python\__pycache__ api\__pycache__
2. Chạy lại: npm run build (hoặc npm run dev).
3. Mở Cấu hình → Cấu hình tính toán để xem 2 khu vực mới và bảng rule đủ chữ.
