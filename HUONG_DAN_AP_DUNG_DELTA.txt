BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build:
       rmdir /s /q .next
       del /s /q python\__pycache__ api\__pycache__
2. Chạy lại: npm run build (hoặc npm run dev).
3. Thử: Tạo đơn hàng → bấm "Lưu nháp" → phải mở trang chi tiết đơn và trạng thái là Đơn hàng mẫu.
