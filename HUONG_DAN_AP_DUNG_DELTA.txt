--------

BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build:
       rmdir /s /q .next
       del /s /q python\__pycache__ api\__pycache__
2. Chạy lại: npm run build (hoặc npm run dev), deploy lại Python function.
3. Xuất thử PDF V2 / Excel V2 và mở trang in để kiểm tra tiêu đề "ĐƠN ĐẶT HÀNG".
