BẮT BUỘC SAU KHI COPY
---------------------
1. Xoá cache build của Next.js để chắc chắn dùng code mới:
       rmdir /s /q .next
       del /s /q python\__pycache__ api\__pycache__
2. Chạy lại: npm run build (hoặc npm run dev) rồi mở tab Cấu hình → Cấu hình tính toán,
   kiểm tra dropdown CÁCH TÍNH KH/LƯỢNG có đủ 5 công thức theo kích thước.
